# Hi, I'm Miguel

Senior full-stack engineer based in Santiago, Chile. I build fintech and Web3 infrastructure in TypeScript, from the API and the React front end down to the Kubernetes cluster it runs on.

Right now I'm Technical Lead & SRE at a fintech group (AndeanWide Capital, Rillis and Hamirach), leading a team of 10 developers.

## What I work on

- **Web3 infrastructure.** A white-label "Stripe for crypto" running in production: custodial wallets, on-chain deposits and withdrawals on EVM chains, stablecoins and crypto↔fiat on/off-ramps, offered to companies through an SDK and API.
- **Compliance tech.** AML and sanctions screening: event-driven data pipelines on AWS and fuzzy name matching that keeps false positives down.
- **Platform and reliability.** AWS with Terraform, GitOps with ArgoCD and Helm, and observability with Prometheus, Grafana and Loki.

Most of this lives in private repositories, so the activity you see here is only part of the picture.

## Side project: Kaudo

Stablecoin payments for remittances into Venezuela, built on Base with ERC-7579 smart accounts and passkey + MPC signing. It's still in development, and you can try the staging environment at [staging.kaudo.app](https://staging.kaudo.app).
